# R21 code--paper consistency audit

**Paper:** `paper/main.tex` and included sections/tables  
**Date:** 2026-08-28  
**Auditor:** independent code--paper audit context  
**Scope:** R21-C1--R21-C4, their manuscript renderings, raw receipts/observations,
R21 paper-input manifest, and separation from the R17/R18/R19 denominators. No
experiment was rerun and no source, paper, or evidence file was modified.

## Verdict

**PASS for code--paper quantitative consistency (4/4 R21 claims).** Every scoped
R21 claim maps to a retained raw result, its normalized paper input, and the
manuscript at the displayed precision. There are no Critical claim discrepancies
and no failed or unverified R21 quantitative claims.

One Major artifact-integrity finding remains: the R21 paper-input manifest is
internally valid but is not a dependency-closed source manifest. This does not
change the 4/4 claim result, but it should be corrected before packaging.

## Code and derivation review

- `r21_feature_baseline.py` constructs a complete database delta from a full
  admission reference, applies it in one transaction with a form-version CAS,
  fingerprints the complete SQLAlchemy metadata snapshot, and aborts if the
  materialized fingerprint differs. The summary uses medians, the project's
  locked nearest-lower percentile definition, and the paired arithmetic mean.
- `r21_trace_optimization.py` groups baseline and current raw rows by the exact
  `(fields, versions, records)` key, rejects unequal cell trial counts, rejects
  optimized observations above the 12-statement budget, and reports descriptive
  sequential-run ratios. The manuscript preserves the sequential-run caveat.
- `query_forms.py` replaces per-field/per-version loads with form-level bulk
  reads and in-memory indices while retaining the value/source, transition,
  decision, certificate, evidence, and authorization checks. The raw SQL count
  independently confirms the fixed 12-statement shape for every observation.
- `experiment.py` uses scenario-specific tool-order and state predicates; the
  retained parsed events and authority receipts satisfy those predicates. It
  does not infer a robustness rate, and the manuscript explicitly avoids one.

## Findings requiring action

### Major 1 — R21 paper-input manifest is not dependency-closed

`source/live-agent-experiment/auto_decte_live_agent/state_probe.py` is directly
used to compute the independent state/version observations and its hash appears
in `live-agent-run-2/run_metadata.json`, but the source file itself is not an
entry in `r21-paper-input-manifest.json`. Likewise,
`source/performance-experiment/benchmarks/authority_cost.py` is directly imported
by both R21 performance modules and supplies the measurement, percentile, full
admission, and trace workload functions, but it is not listed. Consequently, a
mutation of either current source file is not detected by verification of the
paper-input manifest alone.

**Required fix:** add both direct dependencies (and preferably the R21 tests) to
the manifest's source closure, rebuild/verify the manifest, and update the
appendix's source-file count, byte count, and manifest SHA-256. This is an
artifact-integrity gap, not a numeric discrepancy in R21-C1--C4.

## Audit limits

This was a read-only traceability audit. It did not rerun the hosted agent or the
performance experiments, did not assert hardware portability, did not assess
model accuracy/security, and did not replace a full reproducibility or artifact
coherence audit. Raw numeric summaries were independently recalculated from the
retained observations; experiment execution itself was accepted only where
supported by the frozen receipts and hashes.
