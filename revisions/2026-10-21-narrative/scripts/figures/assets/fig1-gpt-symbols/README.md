# Embedded generated object symbols

`symbol-sheet.png` is the unmodified transparent PNG returned by OpenAI's
built-in image-generation tool on 2026-10-21. It is an edited continuation of
the author's requested glyph preview. The service did not report an underlying
model version; no model version is inferred. `PROMPT.txt` records the final edit
request; `PROVENANCE.json` records the sheet hash and placement windows.

The actual generated pixels are embedded in manuscript Figure 1, not replaced
by hand-drawn lookalikes. The three glyphs represent the candidate record,
authorization grant and authoritative state. Blank interiors receive live
Arial labels and values. The c2 identity tab is overlaid with a dark vector
label background; its candidate object otherwise uses the identical asset as
c1. Checks, arrows, stop bar, brackets and column backgrounds are vector shapes.

The placement code reads lossless crop windows from this sheet. The monochrome
companion converts their RGB channels to luminance while preserving alpha.
No experimental observations are encoded in, generated by, or altered by the
image tool. All figure values belong to the explicit conceptual construction.

Figure regeneration uses the saved PNG, NumPy and Matplotlib, with no API call
or external image fetch. The manuscript AI-assisted preparation subsection
discloses the generated symbols. The earlier pure-vector version is preserved
in the repository's `reviews/figure1-imageglyph-2026-10-21/before/` snapshot.
