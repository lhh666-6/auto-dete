## Compile the editable sources

A configured TeX Live installation with pdfLaTeX is sufficient. The documents use standard article, geometry, Latin Modern, amsmath/amssymb, booktabs, tabularx, enumitem, microtype, graphicx, natbib, hyperref, xurl, placeins, longtable, multirow and cleveref packages. No shell escape is required.

Run `bash build.sh` in this directory. It compiles both documents three times, checks unresolved references/citations and overfull boxes, and copies the outputs to `main.pdf` and `supplement.pdf`. Alternatively compile each `.tex` file three times with pdfLaTeX. The PDF figure files are already included, so Python is not needed to compile.

## Regenerate the four diagrams

Run `python3 make_revision_figures.py` with matplotlib available. Source tables and the manuscript aggregate JSON are under `evidence/online/`. The script validates the plotted counts before exporting editable SVG, vector PDF and 400-dpi PNG. The original joint-outcome chart is retained in the supplement and can be regenerated by the archived `make_figures.py` when using the full handoff tree.
