## 使用方式

投稿或发给第二作者评阅时，同时提供 `paper/main.pdf` 和 `paper/supplement.pdf`。两份文档分别编译，Supplement S1–S3 与主稿中的指引对应。

本轮只做长度与叙事精简。前一轮实现测试结果仍由未变更代码及证据支持，没有把编译通过当作新的实验验证。作者名单、独立盲标、新补充包的不可变公开地址等事项继续沿用原状态；当前未上传或替换 GitHub 的 v8 冻结版本。

主稿减少 10 页并不意味着 JSS 一定认可其篇幅或贡献；本报告确认的是实际页数、内容保留与可核查性。
