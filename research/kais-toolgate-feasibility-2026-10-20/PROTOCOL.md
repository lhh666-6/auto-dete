# ToolGate 最小离线可行性验证

日期：2026-10-20。范围：已批准方案 P1 的八个开发控制。

## 问题和边界

原作者 ToolGate 的可配置前置/后置检查，是否能通过正常接口表达并执行本次映射的纠正执行关系？与 C 的原持久准入后端在这些控制中是否一致？

这是接入开发验证，不是最终测试集、完整公共 benchmark、在线 Agent 研究或已发表方法的总体优劣排名。主线之外新增防御场景 **0**。不声称提示注入防御、分布式安全、恶意审查者防御或生产收益。

## 两条实际执行路线

- **T-configured（关系配置）**：固定 ToolGate 作者源码提交 `976ad3f5528f89e248cbdf55840347b445934155`，运行原 `ToolGatePipeline`，在其公开回调中独立实现本文关系。不调用 C verifier。确定性 reasoner 与单工具选择只提供动作，模型调用为 0。
- **C**：复用上轮冻结的 `stores.Store("full", ...)`，调用原 `ReviewForms` 和原 `SqlAlchemyFormRepository`；不重写 C 的准入判定。

八个控制的输入语义一致，候选 ID、转换 ID 在各自表示中可以不同。共享投影是提议、授权值、被审与尝试执行的候选、前驱状态和字段来源；C 的其他证据/生产者元数据不进入本轮比较。不得从这八项推出整个合同的覆盖等价。

条件按接口和代码改动分类：通过正常业务回调可表达的关系不算框架能力突破。**原方案中的 T-configured 与 T+relation 在这里合并为同一个条件**，不能重复计数。本轮不另造一个只检查 schema 的弱 T-configured。ToolGate 没有随源码提供本任务的现成纠正授权政策；本轮明确是**关系配置后的可行性**。独立方法正式比较、其配置来源和开发集外测试仍须另外验收，不能以本轮替代。

## 两个验收终点

1. 比较完成：外部代码忠实运行、配置公平，保留差异、平局、未知和不适用。
2. 贡献判断完成：分别说明原文提出的保证、原生可配置能力、实际增加的状态/持久机制，以及本轮观察。可表达不等于此前已经提出；此前没有提出也不等于框架不能表达。

P0 同时从已有 33 组三路记录重算联合结果，逐项检查六个边界效用差异。仅符合新增合同的合法请求被拒绝才可称误拒；证据不足时保留未知。记录更完整带来的可观察性提升与阻止违规分开报告。

## 提交边界

ToolGate 原顺序是 pre → tool → post → symbolic-state update。工具在本适配中只构建候选后继，不提前写持久状态。SQLite 桥接层在 post 成功后才写入，并在一个事务中包住当前状态读取与本地执行；该桥接、持久记录和关系回调均为本项目新增代码。

因此，不把适配层的提交事务说成 ToolGate 原生具有数据库回滚，不把其纯函数工具的拒绝说成已经撤销任意外部副作用。没有多进程竞争测试，不推出并发 freshness 保证。

## 八个开发控制

| ID | 场景 | 预期业务效果 |
|---|---|---|
| D01 | 提议值原样获批 | 单次合法提交 |
| D02 | 提议值被纠正，执行授权值 | 单次合法提交；保留提议/授权区分 |
| D03 | 已产生同上下文新实例，仍执行原被审实例 | 单次合法提交 |
| D04 | 同上下文新实例被重新授权后执行 | 单次合法提交 |
| D05 | 同上下文新实例沿用旧授权 | 不新增业务提交 |
| D06 | 审查后独立事务推进前驱 | 不新增本次提交；保留独立更新 |
| D07 | 工具候选后继使用提议值而非授权纠正值 | 不新增业务提交 |
| D08 | 工具候选后继改写未被授权的 batch 字段 | 不新增业务提交 |

所有成功案例检查完整后继以及未变字段来源原样保持。D08 验证的是未授权字段改动；**没有测试任意伪造来源描述或证据攻击**。重试回执、生命周期撤销等未进入本轮。

输入、预期和实现文件在执行前以 `FREEZE.json` 固定。它是本地开发运行留痕，不称为正式预注册。发现实现错误时保留旧运行，记录修正，不删除不利结果。

## 判定与保留

独立评分器只读 SQLite 和保存的输入/运行记录，不导入 gate。分别检查：

1. 实际业务版本是否新增、值是否符合预期。
2. 被审/使用实例与授权值能否由持久记录连接。
3. 未变字段值与来源是否保持。
4. 拒绝后业务状态是否不变；候选登记本身不算业务提交。
5. ToolGate pre/post 调用、executor 调用和符号状态是否符合执行记录。

运行错误、不可映射、未知单列，不换算成某一方法的失败。两条实现一致就报告一致，不增设用来寻找优势的案例。

所有运行写入新目录，保留输入、源码 hash、原始输出和 SQLite；禁止覆盖已完成运行。评分可离线重算。提交版、原补充材料和冻结账本不修改。
