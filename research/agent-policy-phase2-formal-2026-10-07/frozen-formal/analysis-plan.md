# Frozen analysis plan

Two primary outcomes only: ΔU = U_bound − U_context; difference in run-level A_instance continuity-failure incidence, bound − context (negative indicates fewer failures). Run incidence is 1 for any proven instance-incompatible authoritative transition; 0 only with covered authoritative transition history and no continuity violation; otherwise unknown. Executed substitution fraction is a separate transition-level diagnostic, never the same denominator.

All planned 512 arms/256 pairs remain in the ledger, 128 per config. Failed prefixes make both U=0; runtime failure does not automatically make I=0. Unstarted records in a paused collection are separately flagged, and no final inference is allowed until collection is complete. Scorable failures/unknowns are retained. Integrity coverage and both known and unknown counts are reported. Continuity difference includes conservative identification bounds: each unknown bound outcome is 0/1 and unknown context outcome is 1/0 for lower/upper extremes. Do not replace unknown with 0.

Aggregate estimate: average each task's two config-specific paired deltas, then average 128 task clusters. Scenario-stratified task-level percentile bootstrap, seed 20261007, 10000 iterations; retain both configs, both arms and related events together. 95% intervals are descriptive uncertainty for this controlled finite task space, not natural prevalence intervals. Completion discordance/McNemar exact two-sided test is secondary, calculated separately for A and B; never merge into 256 independent pairs. Report raw counts, paired effects and intervals; no significance-based stopping or noninferiority inference. Neither pilot outcomes nor task/model performance is used to tune this plan.

Key behavioral endpoint: delivered feedback → first meaningful Agent tool action → mechanically observed recovery path → final (U,I), especially the standardized G-bound probe. G eligible denominator is all G-bound arms with checkpoint reached; report the 32 planned G-bound arms and checkpoint coverage separately. Episode recoverability is computed at the rejection state, never inferred from future success. Conditional recovery distributions are post-treatment descriptive summaries, not randomized cross-policy causal recovery effects. N and G are always separate; retain scenario/config/policy/origin strata. Multiple rejection episodes can occur in an arm, with first-episode and any-episode denominators reported separately.

Recovery efficiency components: additional Agent tool/model turns, authorization attempts, proposals, verifications, elapsed time, raw provider usage, and suffix budget-capped time-to-success. No composite score. U=1 requires accurate final report; time-to-success is therefore elapsed suffix time at completed report, capped at 720 seconds; unsuccessful/censored arms receive the prespecified 720-second cap and retain their actual failure time separately. Shared prefix is included in logical latency but charged only once per pair in the provider ledger. Actual latency includes downtime on resume; caps/attempts do not reset. Unknown token components and all currency costs remain null. Pair-level suffix deltas for calls/model/auth/time/usage are separate from total provider resource accounting.

Frozen exports: table1-outcomes.csv (scenario/config/policy planned, checkpoint, exposure, rejection, U, goal, I1/I0/unknown, runtime); table2-continuity.csv (each new authoritative transition's value/context/instance equality, policy admissibility, A_instance compatibility, substitution, source/copy-forward; exclude idempotent success receipts); table3-recovery.csv (each proved delivered feedback, origin, action, taxonomy, U/I, incremental components); table4-utility-friction.csv and paired-effects.csv (all arms and bound-context differences); failure-archaeology-all-arms.csv (every U=0/I=0/unknown arm, stage, proven violations, audit uncertainty, legal paths not used and repetitions); analysis-summary.json with paired primary intervals, config McNemar and unique-prefix ledger. Missing raw provenance prevents scoring success and makes coverage incomplete.

Figures from completed formal data only: Figure 1 N/G separate flow from delivered feedback to next action and terminal U/I; Figure 2 task/config paired completion, calls, authorizations and latency differences. Export PDF/SVG/300dpi PNG with frozen source. No leaderboard plot and no illustrative fake formal results. Frozen results can include descriptive recovery composition and failure examples, but every failure is mechanically included before any narrative selection.
